## 2. 요건 요약

배포 관리 화면(`/deploys`)에 운영시스템 Select 를 추가해 목록·상태 배지·페이지·현황 탭이 선택한 시스템 기준으로 보이게 한다. 항목은 활성 시스템 전부와 "전체"(기본값)이며, 선택은 상태 필터와 AND 로 작동하고 바꾸면 1페이지로 돌아간다. 필터링은 이미 받아 둔 전체 목록을 프론트에서 거르는 방식으로, 백엔드와 API 함수는 바꾸지 않는다. 선택은 화면을 떠나면 초기화된다(기억하지 않음). 변경 관리(F-CR-004)가 같은 Select 패턴을 따른다.
