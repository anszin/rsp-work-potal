## 2. 요건 요약

변경 관리 화면(`/requests`)에 운영시스템 Select 를 추가해 목록·상태 배지·현황 탭이 선택한 시스템 기준으로 보이게 한다. 항목은 활성 시스템 전부와 "전체", 상태 필터와 AND. **1.1(REQ-2026-004)**: 초기값은 사용자별 — 이 화면의 저장값 → 담당 시스템 1개 → 전체, 바꾸면 localStorage 에 기억한다(키 화면별). 백엔드와 API 함수는 바꾸지 않는다. EXTERNAL 도 전 요청을 보는 현행(L2 9절 결정)이라 Select 항목은 역할과 무관하게 같다. 배포 관리(F-DR-006)와 같은 패턴이며, 변경 관리에는 페이지네이션이 없어 페이지 리셋 요건은 없다.
